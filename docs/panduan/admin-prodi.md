# Panduan Admin Prodi

Admin prodi melihat prestasi yang **melibatkan prodinya** dan menjalankan tahap verifikasi 1 (bila tahap prodi diaktifkan).

## 1. Masuk
1. Login di `/admin` dengan akun admin prodi. Data dikunci pada prodi Anda.

## 2. Antrean tahap 1
1. Menu **Prestasi** → tab antrean *Diajukan*. Tahap 1 hanya untuk prestasi yang pengajunya dari prodi Anda.
2. Klik **Periksa**. Buka tautan bukti lewat tombol tautan (pembukaan tercatat di log), periksa kelengkapan dan kewajaran.
3. Pilih **Loloskan ke fakultas**, atau **Kembalikan untuk perbaikan** / **Tolak** dengan catatan minimal 10 karakter.
4. Ikon peringatan di daftar menandai duplikat atau tautan bermasalah.

## 3. Rekap prodi
- **Dasbor** menampilkan statistik prodi (filter tahun). Prestasi tim lintas prodi dihitung di setiap prodi anggota.
- **Peringkat Poin** (bila poin aktif) menampilkan peringkat mahasiswa prodi.

## 4. Laporan akreditasi
1. Menu **Laporan** → pilih **Akreditasi** (lampiran per prodi), pilih prodi dan periode.
2. Ekspor kecil langsung diunduh; ekspor besar diproses antrean dan muncul di **Berkas Ekspor** (tersedia ≤ 24 jam).

## Tanya-jawab
- *Prestasi tidak muncul.* Pastikan salah satu anggota berasal dari prodi Anda.
- *Ambil alih oleh fakultas.* Admin fakultas dapat mengambil alih dengan catatan; riwayat tercatat.
